# LaysanX Atlas

Atlas is a dynamic storefront and website theme for LaysanX.
It uses the platform's Liquid-like theme engine and backend content; opening
the HTML templates as a standalone static site will not render live data.

## Use

Choose **Code > Download ZIP** on this repository, or download the
[v2.0.0 release ZIP](https://github.com/LaysanX/atlas-theme/releases/latest/download/laysanx-atlas-v2.0.0.zip).
Upload either ZIP directly in LaysanX Client Admin > Themes; no unpacking or
repackaging is needed. Both include `theme.json`, `templates/`, `sections/`,
`assets/`, and the MIT license.
